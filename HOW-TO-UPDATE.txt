Laptops / other PCs (optional): the team plugin now carries docs-http (the VM's docs service, native HTTPS, no Python needed)
  1. TCP 8001 open from the PC to the VM
  2. Trust the VM's certificate once (copy /etc/paas/tls/paas-ui.crt from the VM):
       Windows PowerShell:  Import-Certificate -FilePath .\paas-ui.crt -CertStoreLocation Cert:\CurrentUser\Root
       RHEL:   cp paas-ui.crt /etc/pki/ca-trust/source/anchors/ && update-ca-trust
  3. claude plugin marketplace add <gitlab url of brain-flashback>
     claude plugin install paas-brain-flashback@paas-brain-flashback
  4. Check:  claude mcp list   ->  plugin:paas-brain-flashback:docs-http ... Connected
     (Failed with SELF_SIGNED_CERT = step 2 missing; timeout = step 1)
  A PC that already has the plugin: once  claude plugin marketplace update paas-brain-flashback
     && claude plugin update paas-brain-flashback@paas-brain-flashback   (after that updates come by themselves)
  docs-local on a PC needs Python 3 (it serves the team notes from the clone); docs-http does not. On the VM docs-http is
  switched off by the managed settings (docs-local there has the same library), so nothing is listed twice.
