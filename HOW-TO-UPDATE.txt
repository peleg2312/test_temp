Storage brain update 2b433c1 -> 0f05dc7
=======================================
For a VM that already has the 2b433c1 update (storage-brain-update-2b433c1-with-ui.zip). No new web UI bundle needed.
What is in it:
  - PowerPoint decks (make-deck skill): designed, editable .pptx; clean or bold style, 41 icons, charts with target lines
    and labelled series, tables with status colours / heat / totals; every deck its own look (layouts, palette, fonts),
    or the company template
  - Opus (1M context) selectable again in the web UI and /model; the default stays plain Opus
  - The regular model's context window (when chats are summarised): Users tab "Chat context window", or paas-user context
  - The compaction summary is shown as the summary, no longer as a message you sent
  - Sign-in page: no false "Caps Lock is on"

1. Download storage-brain-update-0f05dc7.zip (24 MB).
2. Check it: SHA-256 must be
     1f856a988233a3ca46415dcde55d8d3c923a5f76947a4ce51d9d00f5b559a2b0
     Linux: sha256sum storage-brain-update-0f05dc7.zip      Windows PowerShell: Get-FileHash storage-brain-update-0f05dc7.zip
3. Copy it to the VM (e.g. WinSCP, or: scp storage-brain-update-0f05dc7.zip root@<vm>:/root/), then on the VM as root:
     cd /root
     unzip -o storage-brain-update-0f05dc7.zip
     sh update-2b433c1-0f05dc7/apply-update.sh /path/to/storage-mcp-servers
     cd /path/to/storage-mcp-servers && sh brain/multiuser/install-multiuser.sh
     systemctl restart 'paas-ui@*'
   Kept: ports, tokens, Market items, notes, skills, plugins, MCP servers. Safe to run twice.
4. Context window (optional), as root:  paas-user context 300000     (or the Users tab; paas-user context prints it)
   Set it no higher than the model behind the gateway really accepts. New sessions use it.
5. Checks:
     grep -c DISABLE_1M /etc/claude-code/managed-settings.json        -> 0
     /opt/paas/devtools-venv/bin/python -c "import pptx; print('python-pptx', pptx.__version__)"
     python3 ~/.claude/tools/deck.py --example > /tmp/ex.json && python3 ~/.claude/tools/deck.py /tmp/ex.json    -> "checks: ok" and a "look:" line
     python3 ~/.claude/tools/deck.py /tmp/ex.json --look random                                                  -> another design
   In the web UI: the model picker shows "Opus (1M context)"; a new chat's default is Opus.
   Optional preview images for decks: dnf install libreoffice-impress poppler-utils
6. Use: in a new chat, "make a presentation of ...". A look you liked: "use look 1234 again". Company look: give the path
   of the company .pptx / .potx once.
