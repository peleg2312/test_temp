1. Check both downloads:
     storage-brain-update-b7012cb.zip (24 MB)         SHA-256 c249cb131d00e23073953a868f738baca35af2bec17de524375afdbfb12de05e
     flashback-library-2026.11.04.zip (144 MB)        SHA-256 1bf1b7c633106e2076147b473cd326c9d79cbb4ae95a166046047e17f1ebfdd2
       (inside: flashback-library-2026.11.04.tar.gz  70e047164684031a6f14eacce37acb15146ee3b8cc9f0db83db084228c347ef2;
        paas-library import checks it against the .sha256 next to it)
     Windows: Get-FileHash <file>        Linux: sha256sum <file>
2. Copy both to the VM (/root), then as root:
     cd /root && unzip -o storage-brain-update-b7012cb.zip
     sh update-2b433c1-b7012cb/apply-update.sh /path/to/storage-mcp-servers
     cd /path/to/storage-mcp-servers && sh brain/multiuser/install-multiuser.sh
     systemctl restart 'paas-ui@*'
3. The library (as root):
     cd /root && unzip -o flashback-library-2026.11.04.zip
     /opt/paas/bin/paas-library import flashback /root/flashback-library-2026.11.04.tar.gz
     /opt/paas/bin/paas-library list                   -> flashback  31356 documents  218 MB ...   (about 30 s)
4. The team repository: an empty GitLab project (e.g. storage/brain-flashback, branch main, members Developer), then:
     python3 brain/teams/publish.py flashback --to /opt/paas/teams/flashback --remote <gitlab url>
   (or re-run install-multiuser.sh with --team flashback=<gitlab url>; add the team's AD group to its --groups)
5. Commvault MCP per CommCell: Brain tab -> Team -> More -> Edit a team (team flashback):
     commvault-env1 / -env2 / -env3: url http://<host>:<port>/mcp, header Authorization = the secret your Commvault MCP
     setup stored (no "Bearer"). Use a view-only Commvault user. ontap / powermax / powerflex: same addresses and read-only
     tokens as the SAN team.
6. Each member: Brain tab -> Team -> Flashback, new chat, then:
     /paas-brain-flashback:brain-setup          (tool map; then fill environment.md: CommCell names and versions etc.)
   Try:  "morning check"   "why did job 123456 fail on env2"   "prepare a restore of database X on SQL AG Y to yesterday 22:00"
         "are the hosted cluster backups ok on mce-a"   "restore hosted cluster Z from the last good backup"
         "what does this Veeam error mean: <paste>"   "SnapMirror lag of the backup volumes"
