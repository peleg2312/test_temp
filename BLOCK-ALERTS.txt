Standalone: works with any brain or none, on the VM or a laptop. Needs python3 3.9+ (RHEL 9 has it).
The email's HTML is fixed inside the skill (block_alerts_mail.py); Claude only fills the content and runs it.

INSTALL (on the VM)
  cd /root && cp /path/to/test_temp/block-alerts-0b3193d.zip .
  sha256sum block-alerts-0b3193d.zip                       # must print a1d0e295f24792e464d49bb4c38a9392f05cf4ae9d07d2349086520b096d0847
  unzip -q -o block-alerts-0b3193d.zip && cd block-alerts-0b3193d
  sh install.sh --check              # "ok: the script builds the example email"
  sudo sh install.sh --all           # every user + users created later
     (only for yourself:  sh install.sh)
  Start a new Claude chat, then:  "block alerts: the PowerMax and MDS alerts of the last 24 h, email them to me"

SEE THE EMAIL FIRST:  open block-alerts/examples/email.eml in Outlook (a draft; nothing is sent)
  examples/email-all-clear.html: how a quiet night looks
MAIL SETUP: Claude asks for your SMTP relay the first time; the password goes in a file only you can read
  (install -m 600 /dev/null ~/.config/block-alerts/smtp.pass). Test: python3 ~/.claude/skills/block-alerts/block_alerts_mail.py --check
