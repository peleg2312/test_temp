PAAS-KIT  -  separate from the storage brain update
====================================================
File: paas-kit-fba5051.zip   (352M)   SHA-256: 7f172215ce33b065fda602bbb5ed6852c39cb88468c06861009b6ed56d92a816

A separate zip, not part of the brain. Install it once as root. rtk and Headroom are on for every user on the VM
(also users created later), whatever brain they use; only root can turn them off. The coding plugins are in the paas
Market: each user adds the ones they want. It never changes the brain, a team repository, managed-settings.json or anyone's own settings.

  rtk                 shorter shell output (rtk's own hook, patched and tested command by command): every problem
                      pod with its real reason, whole grep lines, no list cut. Left as typed because rtk loses facts
                      there: oc/kubectl logs and describe, aws, ps, ruff, ls -l. 18 ms per command.
  Headroom            makes the model's input smaller. Default profile safe, strictly lossless: JSON lists become
                      compact tables, every row and value kept (measured: volume list 70%, host list 53%, port list
                      68% fewer tokens). Logs and documents reach GLM unchanged. Kompress is not shipped (little gain,
                      ~0.8 GB RAM, damaged answers). If it stops, sessions go straight to GLM.
  MEASURED TOGETHER   one session of 8 shell commands + 4 MCP results: 96,263 tokens plain -> 88,984 with rtk (8%)
                      -> 43,878 with rtk + Headroom safe (54% fewer), nothing left out except what rtk prints a
                      "rtk recall <hash>" for.
  code-graph (Market) a graph of the git repository for large code bases: what a change breaks, callers of callers,
                      review (measured 2.4x faster on those questions). /code-graph:build once per repository.
  fastapi-api (Market) Python REST APIs offline: /fastapi-api:new <name>, paas-kit venv, rules, api-reviewer agent.
  ast-grep            structural code search on the PATH.
  ponytail (Market)   coding mode: smallest correct change, never cutting validation, security or tests. Off by default;
                      a plugin of the paas Market (the installer adds it there if the brain does not carry it yet);
                      each user adds it in the Market. Root, for everyone: paas-kit plugin on ponytail. Needs node.
  Not included: Go (dropped on request).

INSTALL  (on the VM, as root; needs python3.12:  dnf install -y python3.12; ~1.5 GB free in /opt)
  cd /root && cp /path/to/test_temp/paas-kit-fba5051.zip .        # the folder you git-pulled
  sha256sum paas-kit-fba5051.zip                               # must print 7f172215ce33b065fda602bbb5ed6852c39cb88468c06861009b6ed56d92a816
  unzip -q -o paas-kit-fba5051.zip
  sh paas-kit/install.sh
     -> at the end "model ... <your GLM address>" and "new sessions  through Headroom".
     -> "model address: NOT FOUND": run it again with your address:
        sh paas-kit/install.sh --upstream https://<the GLM address Claude uses today>
  paas-kit status
  Then start a new chat in the web UI (running chats keep the old setting until restarted).

CHECK THAT IT WORKS
  in a new chat (auto mode): "run git log -5 --stat and ls -la"   the output comes back in rtk's compact form;
                                       after a while: paas-kit gain   (each user's rtk savings)
  paas-kit status                      Headroom "answering", "new sessions through Headroom", savings after some use
  in a new chat inside a git repo:     /code-graph:build      then ask "who calls <function>?"
  journalctl -u paas-headroom -n 50    the Headroom log

TURN THINGS OFF / REMOVE (root)
  paas-kit headroom off                sessions straight to GLM again (on: paas-kit headroom on)
  paas-kit plugin off rtk              rtk off for everyone (on: plugin on rtk)
  paas-kit plugin on code-graph        a Market plugin forced on for everyone (off: back to each user's choice);
                                       also fastapi-api, ponytail
  paas-kit headroom profile full       Headroom: every compressor + Kompress (back: profile safe, the default)
  sh /opt/paas-kit/kit/uninstall.sh    removes everything the kit added

FROM AN EARLIER paas-kit (any version)
  the same steps; settings are kept. This version: rtk for everyone; code-graph, fastapi-api and ponytail are paas Market plugins each user adds
  (an earlier kit's forced code-graph / fastapi-api become each user's choice). Before: rtk audited and
  patched, no Kompress, Headroom with 1-4 workers, offline speed settings.

UPDATE LATER
